# 컨셉 이미지 요청: 산출물 오케스트레이터

> **요청 대상:** GPT (이미지 생성)
> **요청자:** 저장소 소유자 (Claude가 대신 정리)
> **결과물 위치:** `artifact-orchestrator/docs/concept/` 폴더에 PNG로 커밋하거나, 이 요청의 GitHub 이슈에 첨부

## 1. 제품 개요

사내 여기저기 흩어진 **FastAPI 웹앱과 HTML 산출물**을 모아 관리하는 웹 도구입니다.

- 뒤섞인 공유폴더를 스캔해 산출물을 자동으로 찾아냅니다.
- 각 산출물의 수준(완성도, 코드 품질, 유지보수성, 보안, 성숙도 Lv.1~5)을 진단합니다.
- **투자 확대 / 현상 유지 / 개선·통합 / 정리·폐기** 판정(Gartner TIME 모델)을 제안합니다.
- 다음 개발 과제(로드맵)를 제시합니다.
- 기능이나 데이터가 겹치는 산출물을 묶어 통합 방안을 제안합니다.
- AI는 **사내 설치형 LLM**만 사용하므로 외부로 데이터가 나가지 않습니다. 보안을 중시하는 기업 내부 도구라는 점이 핵심 컨셉입니다.

현재 구현된 화면은 `artifact-orchestrator/app/templates/` 아래에 있습니다. 이번 요청은 이를 **더 완성도 높은 제품 디자인으로 발전시킨 컨셉안**입니다.

## 2. 요청 이미지 (총 4장)

### ① 포트폴리오 대시보드 (메인 화면)
- 상단: 다크 네이비 헤더, 제품명 "산출물 오케스트레이터", 메뉴(포트폴리오, 통합 후보, 내보내기), 우측에 "사내 LLM 연결됨 🟢" 상태 표시
- KPI 카드 6개: 등록 산출물 128, 평가 중 3, 투자 확대 18, 현상 유지 41, 개선·통합 37, 정리·폐기 29
- 좌측 큰 카드: **TIME 4분면 맵**
  - 가로축: 업무 가치, 세로축: 기술 상태
  - 사분면 색: 우상단 투자 확대(초록), 좌상단 현상 유지(회색), 우하단 개선·통합(주황), 좌하단 정리·폐기(빨강)
  - 그 위에 점(산출물) 수십 개
- 우측: "공유폴더 일괄 스캔" 입력창과 버튼, 최근 활동 타임라인
- 하단: 산출물 목록 표 (이름, 유형 FastAPI/HTML, 담당 부서, 성숙도, 기술·가치 막대, 판정 배지, 통합 그룹)

### ② 산출물 상세 진단 화면
- 제목 예: "영업 실적 대시보드", 판정 배지 "개선·통합"
- 점수 카드: 종합 70, 기술 48, 업무 가치 92, 성숙도 Lv.2 프로토타입
- 좌측 "AI 진단": 요약, 강점, 위험 요소 (예: "DB 비밀번호 하드코딩")
- 우측 "개발 로드맵": 번호가 매겨진 단계 카드 (비밀번호 분리 → 인증 추가 → README 작성 → 통합)
- 세부 점수 레이더 차트 (완성도, 코드 품질, 유지보수성, 보안, 업무 가치)
- 정적 분석 칩: API 목록, 사용 DB 테이블, ✓/✗ 체크 (README, 테스트, Docker, 인증)

### ③ 통합 후보 화면
- 겹치는 산출물들을 **노드-링크 그래프**로 표현
  - 노드: 산출물
  - 선: 공유하는 DB 테이블이나 API 이름이 라벨로 붙은 연결
- 예: "실적대시보드", "월간매출_최종_v2", "지역별매출.html" 세 개가 `sales_orders` 테이블로 연결됨
- 우측 패널 "통합 방안": 통합 서비스명 "영업 분석 포털", 기반 산출물, 작업 단계, 정리 대상

### ④ 컨셉 일러스트 (소개용 1장)
- 왼쪽: 여기저기 흩어진 HTML 파일, 서버, 폴더 아이콘이 어지럽게 놓인 모습
- 가운데: 지휘봉을 든 오케스트라 지휘자 모티프 또는 정리 엔진
- 오른쪽: 4분면으로 깔끔하게 분류·정리된 결과
- 사내 서버 안에서만 동작한다는 의미로, 전체를 자물쇠나 방패가 있는 경계선 안에 배치

## 3. 디자인 가이드

- **톤:** 신뢰감 있는 B2B SaaS 스타일. 깔끔하고 정보 밀도가 높되 복잡하지 않게.
- **색상:**
  - 기본: 화이트와 연회색 배경, 다크 네이비 헤더, 포인트 블루 `#2f5bea`
  - 판정 색: 투자 확대 `#12805c` / 현상 유지 `#5b6b82` / 개선·통합 `#c26a00` / 정리·폐기 `#c2392b`
- **글꼴:** 한글 산세리프 (Pretendard 또는 Noto Sans KR 느낌)
- **언어:** 화면 안의 모든 텍스트는 **한국어**
- **해상도:**
  - 화면 시안(①~③): 데스크톱 16:9, 1920×1080 이상
  - 일러스트(④): 가로형
- 라이트 모드 기준이며, 가능하면 ①의 다크 모드 버전도 1장 추가
