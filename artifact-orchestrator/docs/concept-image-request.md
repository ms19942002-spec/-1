# 컨셉 이미지 요청: 산출물 오케스트레이터

> **요청 대상:** GPT (디자인 아이디어 + 이미지 생성)
> **결과물 위치:** `artifact-orchestrator/docs/concept/` 폴더에 커밋하거나, 이 요청의 GitHub 이슈에 첨부

## 부탁드리는 것

화면 구성, 레이아웃, 색상, 시각화 방식은 **자유롭게 제안해 주세요.**
정해 둔 양식은 없습니다. 이 제품을 어떻게 보여 주면 좋을지에 대한 **새로운 아이디어**를 얻고 싶습니다.
현재 프로토타입 화면(`app/templates/`)은 참고하지 않으셔도 되고, 오히려 그와 다른 방향을 환영합니다.

## 제품이 해결하려는 문제

- 회사 안에 직원들이 각자 만든 **FastAPI 웹앱과 HTML 산출물**이 공유폴더, 개인 PC, Git에 뒤섞여 있습니다.
- 무엇이 있는지, 어느 정도 수준인지, 계속 키울 가치가 있는지, 서로 겹치는 것은 없는지 아무도 모릅니다.

## 제품이 하는 일

- 뒤섞인 폴더를 훑어 산출물을 자동으로 찾아냅니다.
- 각 산출물의 수준(완성도, 품질, 보안, 성숙도)을 진단합니다.
- 계속할 가치가 있는지 판단합니다. 키울 것, 유지할 것, 고치거나 합칠 것, 정리할 것으로 나눕니다.
- 산출물마다 앞으로 어떻게 개발하면 좋을지 방향을 제시합니다.
- 기능이나 데이터가 겹치는 산출물을 찾아 어떻게 합칠지 제안합니다.
- AI는 **사내에 설치한 모델만** 사용하고, 데이터는 회사 밖으로 나가지 않습니다.
- AI는 1차 진단만 하고, **최종 결정은 사람**이 내립니다.

## 사용자

- IT·DX 담당 부서: 전사 산출물 현황을 파악하고 정리 방향을 정합니다.
- 경영진·팀장: 어디에 투자하고 무엇을 정리할지 한눈에 보고 결정합니다.
- 산출물을 만든 직원: 내 산출물의 평가와 개선 방향을 확인합니다.

## 요청 사항

- 서로 다른 **디자인 방향 2~3가지**를 제안해 주세요. 방향마다 간단한 설명(컨셉, 의도)을 붙여 주세요.
- 어떤 화면을 몇 장 그릴지도 자유입니다. 이 제품의 핵심 가치가 가장 잘 드러나는 장면을 골라 주세요.
- 제품을 소개하는 컨셉 일러스트도 좋습니다.

## 최소 조건

- 화면 안의 텍스트는 **한국어**로 해 주세요.
- 이미지마다 사용한 **프롬프트**를 함께 남겨 주세요. 나중에 수정을 요청할 때 필요합니다.
